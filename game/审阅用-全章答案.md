# 审阅用：全章答案（剧透，勿给玩家）

照下面的步骤操作，可以从序章一路通关，拿到“好”结局。每一步都可以故意做错，用来测试上级医师意见和翻车。

通用操作：
- ← → 或 A、D 左右走动，也可以点地面；走到人物或物件旁边，头顶出现“回车”，按回车、空格或 E 交互。直接点人物或物件，小人会自己走过去。
- 对话点空白处或按回车继续；黄底的对话句点一下就收入信息板。Esc 关闭选项。
- HIS 里每一行都要点开，数值才会显示并收入信息板。
- 汇报时点“＋ 新论点”选卡，再点卡上的“＋ 论据”，然后到右侧信息板点条目；点完再点一次那个按钮结束选择。
- 标题页“审阅用：从某一章开始”可以直接跳到任一章。

---

## 序章 · 接诊

1. 找**师姐**，选“听交班”，点取三句黄底对白（E01）。
2. 点**外院资料**，打开“外院化验”，把每一行点开（E02）。
3. 找师姐，选“资料看完了，去床旁吧”。

## 第一章 · 黄灯停

**探索**
- **患者**：问路上有什么变化、问头痛和精神状况、查体：皮肤黏膜与一般情况、查体：腹部。可选：了解以前怀孕的情况、问以前体检和平时身体（第六章要用）。
- **家属**：问家属路上的情况（发热、寒战）。
- **监护仪**：看生命体征。
- **师姐** → “我想提个建议”：评估胎儿情况、持续复评神经系统情况。这两条是进入条件。
- 测试叙事引导：建议“腹部 CT”，家属会反对（患者 −1）。

**汇报**

| 题 | 论点 | 论据 |
|---|---|---|
| Q1.1 有哪些临床特点？ | 黄疸进行性加深 | 黄染：较前加深 |
|  | 发热伴寒战 | 发热：Tmax 39℃，伴寒战 |
|  | 右上腹痛 | 腹痛：右上腹痛，NRS 5 |
|  | 皮肤黏膜出血 | 出血表现：瘀点、牙龈渗血 |
| Q1.2 如何解释黄疸？ | 胆汁淤积（可能） | 外院 GGT 198、ALP 220 |
| Q1.3 目前有哪些判断？ | 胆道梗阻（待查）或 肝胆系统感染（待查） | 腹痛或发热 |
|  | 出血倾向／血液系统异常（待查） | 出血表现 |

错误测试：Q1.1 加“Murphy 征阳性”或“意识障碍”；Q1.2 加“溶血已确诊”；Q1.3 加“HELLP 综合征（确诊）”。

## 第二章 · 歧路

**探索**：HIS 打开急诊血常规、急诊生化、急诊凝血、炎性指标与胰酶、MRCP 报告，逐行点开。
可选：对师姐建议“ADAMTS13 检测”（已看过血常规时，临床 +2，第五章开场台词会改变）。

**汇报**

| 题 | 论点 | 论据 |
|---|---|---|
| Q2.1 有哪些异常？ | 贫血 | HGB 70 |
|  | 血小板严重减少 | PLT 18 |
|  | 胆红素显著升高、以直接胆红素为主 | 急诊 TBil / DBil |
|  | 胆总管下段狭窄 | MRCP |
| Q2.2 如何解释这些异常？ | 胆道梗阻 | MRCP **和** 胆红素（两类都要挂） |
|  | 胆道感染（胆管炎） | 发热寒战 **和** hsCRP 或血常规 |
| Q2.3 目前考虑哪些诊断？ | 胆总管梗阻 | MRCP |
|  | 急性胆管炎 | 发热寒战 |
|  | TMA 待鉴别（或 血液系统问题待查） | PLT 18 |

挂着论据写“TMA 待鉴别”，临床 +2（与建议 ADAMTS13 的奖励只计一次）。
错误测试：Q2.1 加“凝血时间明显延长”或“超声未见异常”；Q2.2 的“胆道梗阻”只挂 MRCP；Q2.3 加“血液异常都由胆管炎引起（确定）”。

## 第三章 · 山重水复

**探索**：点**会诊白板**，选至少两个候选解释（如“胆道梗阻／胆管炎”“TMA”），在任意格子上点一下做标记。白板不判分。

**汇报**

| 题 | 论点 | 论据 |
|---|---|---|
| Q3.1 工作诊断是什么？ | 胆总管梗阻 | MRCP |
|  | 急性胆管炎 | 发热寒战、hsCRP |
| Q3.2 鉴别诊断有哪些？ | TMA | PLT 18、LD 915 |
| Q3.3 哪些判断尚不确定？ | 血液异常的机制未证实 | 可不挂 |
|  | 胆道诊断不能解释全部表现 | 可不挂 |

错误测试：Q3.2 加“已排除 DIC”或“孕 19 周可排除 HELLP”；Q3.3 加“所有异常已能用胆管炎解释”。

## 第四章 · 乱麻

**探索**
1. HIS 打开“产科超声”并点开。没看过就去谈话室，师姐会拦住。
2. 去**谈话室**，点“患者和家属”，6 个节点**都选第一个选项**（患者 +6）。
   - 测试转院警告：都选最后一个选项，家属会说“要不我们转去别的医院”，然后重谈一次。第二次还谈砸，刘主任接手。
   - 节点 4 选“那就等血小板升上来再做”，刘主任会进门纠正（临床 −2）。
3. 回工作站，对师姐说“谈完了，去找主任汇报吧”。

**汇报**

| 题 | 论点 | 论据 |
|---|---|---|
| Q4.1 处置方案是什么？ | 及时胆道引流（团队评估下） | MRCP |
|  | 抗感染 | 发热寒战 |
| Q4.2 如何权衡利弊？ | 引流可解除梗阻、控制感染 | MRCP |
|  | 血小板低，操作出血风险高 | PLT 18 |
|  | 胎死宫内需产科同步处理 | 产科超声 |
| Q4.3 如何交代病情？ | 当前已知病情 | MRCP |
|  | 胎儿情况如实告知 | 产科超声 |
|  | 引流的必要性 | MRCP |
|  | 操作风险（含出血） | PLT 18 |
|  | 替代方案与不确定性 | 可不挂 |

翻车测试：Q4.1 加“暂不处理，观察”。错误测试：Q4.2 加“必须先把血小板输到正常”；Q4.3 加“暂时不告诉她胎儿情况”。
通过后开放 ERCP 记录（E19）。

## 第五章 · 退潮

**探索**
1. HIS 打开四张新单子：引流后生化、引流后血常规、引流后尿检、网织红与外周血涂片，逐行点开。
2. 去 ICU 找**护士**，选“听交班”，点取发热、头痛两句。
3. （可选）回工作站对师姐说“有紧急情况”，勾上 HGB、PLT 或涂片中的任意一条。汇报前这样做，临床 +1。
4. 对师姐说“查房了，我们走吧”。

**汇报**

| 题 | 论点 | 论据或时序 |
|---|---|---|
| Q5.1 病情有何变化？ | 局部改善 | TBil 180.2 |
|  | 整体仍危险 | HGB 60、PLT 约 20 |
| Q5.2 目前诊断是什么？ | 微血管病性溶血（MAHA） | 外周血涂片、网织红 10% |
|  | 血小板消耗 | PLT 约 20 |
|  | 疑似 TTP | 可不挂 |
| Q5.3 处置原则是什么？ | 治疗前取血送 ADAMTS13 活性 | 治疗前 |
|  | 联系血液科、血浆置换、糖皮质激素 | 立即 |

翻车测试：Q5.3 加“等 ADAMTS13 回报再定”，或把血浆置换标成“结果回报后”。

**MDT**（每轮最多出 3 张）

| 轮次 | 能说服对方的出牌 |
|---|---|
| 血液科 | 证据：外周血涂片、PLT 约 20；时序与判断：高度怀疑 |
| ICU | 证据：Cr 120；机制：肾脏受累 |
| 消化科 | 证据：TBil 180.2；诊断：疑似 TTP；救治动作：继续抗感染 |
| 产科 | 救治动作：产科评估与协调；时序与判断：同时进行 |

**行动排序**：取样、联系血液科、血浆置换、激素放“立即”；继续抗感染、产科评估与协调放“同时进行”；复核诊断放“结果回报后”。

**病房谈话**：7 个节点都选第一个选项（患者 +7）。之后开放 ADAMTS13 结果（E24）。

## 第六章 · 始作俑者？

**探索**：HIS 打开自身免疫检查、抗磷脂相关检查、24 h 尿蛋白、治疗经过记录，逐行点开。第一章没问到既往史的，去病房找患者问“以前怀孕的情况”和“以前体检和平时身体”。

**汇报**

| 题 | 论点 | 论据 |
|---|---|---|
| Q6.1 最终诊断有哪些？ | 胆道梗阻／胆管炎 | ERCP 所见 |
|  | iTTP | ADAMTS13 活性、抑制物抗体 |
|  | SLE（高度考虑） | 日晒红斑等系统症状 **和** ANA 等免疫学检查 |
|  | 胎死宫内 | 产科超声 |
| Q6.2 各诊断有何关联？ | SLE 背景与 iTTP：支持相关 | ANA **和** 抑制物抗体 |
|  | 溶血→色素结石→梗阻：可能机制，未证实 | 黑胆汁（可选） |
| Q6.3 哪些问题尚未解决？ | 胆管狭窄／梗阻的病因 | 可不挂 |
|  | 抗磷脂抗体是否持续阳性 | 可不挂 |

错误测试：Q6.1 加“APS（确诊）”；Q6.2 加“溶血→色素结石→梗阻：已证实”；Q6.3 加“补体未活化，可排除补体介导 TMA”。
通过后开放会诊意见（E31）和原病例后记（E32），然后进入结局。
