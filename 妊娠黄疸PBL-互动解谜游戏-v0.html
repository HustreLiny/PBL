急诊首诊化验（外院带入） —— 点击「提示」展开解读

项目数值提示
ALT / AST82 / 147 U/L
病毒性肝炎多呈 ALT > AST；AST>ALT（倒置）更见于酒精性肝损、肝窦/微血管损伤与溶血成分（HELLP/TMA），且升高幅度温和，不支持「>10–20×ULN 的急性肝炎」。
TBil / DBil72 / 32 μmol/L
结合型约 44%，介于「溶血性（间接为主）」与「淤胆性（结合为主）」之间 → 提示肝细胞性/混合性；必须结合 尿胆红素、尿胆原、GGT/ALP 才能定位受损环节。
GGT198 U/L
GGT 不像 ALP 那样随胎盘同工酶升高，故 198 是可靠异常；明显升高支持胆汁淤积成分。ICP 的 GGT 多正常或轻度升高，故不太像 ICP。
ALP220 U/L
孕中晚期 ALP 可因胎盘同工酶而生理性升高，单独看参考价值有限；需联合 GGT 判定是否为真性淤胆。
LDH781.5 U/L
LDH 显著升高提示溶血或组织坏死；与 AST>ALT、牙龈出血（血小板？） 合并，指向微血管病性溶血（HELLP / TTP）。
Cr99 μmol/L（59–104）
肾功能暂正常，但「溶血 + 血小板减少 + 肾损」是 TMA 的典型三联，必须动态复查 Cr 与尿蛋白。
危险信号 ①溶血 / 组织坏死：LDH 高、AST>ALT
危险信号 ②胆汁淤积：GGT、ALP 明显升高
危险信号 ③出血倾向：牙龈出血 —— 血小板或凝血异常？

题眼：孕中期出现「淤胆 + 溶血 + 出血 + 头痛」的组合，别只想「病毒性肝炎」，要优先摆出妊娠特异性肝病。

第一幕小结

  • 血压偏高 + 下肢水肿 → 必须筛子痫前期/HELLP（不能只盯肝）。
  • 牙龈出血 → 血小板是生死线，下一步必须查（老师「死穴」之一）。
  • 混合性黄疸 + LDH 极高 + AST>ALT → 指向微血管病 / 妊娠特异性肝病。
  • 追问挖出「血小板低 + 光敏 + 口腔溃疡 + 脱发 + 复发性流产」→ 自身免疫病的暗线浮出。
  • 宫高相符但未闻及胎心（疑胎死宫内）→ 需超声确认，影响后续处置与 DIC 风险。
下一幕（Act II 检验·影像）将围绕「三黄疸归类 + 胆道梗阻证据」展开。

复盘 · 推理链与诊断清单

第 1 层 · 孕中期黄疸 / 发热 / 出血 → 筛三类黄疸（混合性 + 溶血成分）
第 2 层 · 转诊急诊：Charcot 三联征 + MRCP 胆道梗阻 → 急性胆管炎
第 3 层 · ERCP 减压后胆红素↓，但溶血 / 血小板 / 肾损 / 发热头痛「不改善」→ 识别 TMA
第 4 层 · ADAMTS13 <5% + 抑制物阳性 → 确诊 iTTP
第 5 层 · 复发性流产 + 光敏 / 口腔溃疡 / 脱发 + 自身抗体谱 → 根因 SLE（+ 继发 APS）

诊断清单（最终）

诊断关键依据
系统性红斑狼疮（SLE）·根病/主干ANA 1:1280、抗 ds-DNA ↑、抗 Sm/RNP/rRNP +++、C3/C4↓、IgG 26 g/L ↑、光敏、口腔溃疡、脱发

继发性抗磷脂综合征（APS）LA 2.2 阳性；解释复发性流产 / 胎死宫内

根病是 SLE：它产生抗 ADAMTS13 抗体（→ iTTP）、抗磷脂抗体（→ APS → 复发性流产），免疫复合物沉积（→ 狼疮肾炎），慢性溶血又通过色素性结石堵了胆道——「一源多响」。
