# 固定病程与叙事引导

患者的医学病程始终固定为原病例，不因玩家的选择出现恶化、死亡或其他反事实分支。玩家的选择只影响临床评价、患者评价，以及患者和家属对玩家这条线的反应所构成的好、中、坏结局。玩家的行动方向通过游戏内的理由（家属反对、上级安排等）被引导回原病例已有资料的范围，从而保证每一条可见结果都有真实来源，不需要编造检查或病程。

## Considered Options

- 按分数改变医学结局：放弃。这会要求编造原病例没有的病程和检查结果，与教学上“事实只来自原病例”的要求冲突。
- 用系统提示直接告诉玩家“本病例未提供此项结果”：只在叙事引导无法覆盖时作为兜底，因为它会破坏沉浸感。
